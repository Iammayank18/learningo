## RULES

1. **Overload nahi.** Agar week ke topics nahi aaye, week extend hoga (Week 4 → 4A, 4B). Ye failure nahi hai, plan hai.
2. Har week: **Day 1–4 Learn · Day 5 Practice · Day 6 Revision + Interview Practice · Day 7 Exam**
3. Exam ke questions is book mein nahi. Exam day pe alag se.
4. **Har exam se pehle apna expected score likho.** Asli cheez score nahi — predicted aur actual ka gap hai.
5. Har topic: Intuition → Core concept → Internal working → Example → Real-world → Common mistakes → Interview questions → Follow-ups → Implementation → Mini test.
6. Difficulty: L1 Concept → L2 Basic implementation → L3 Medium → L4 Unseen → L5 Interview → L6 Real-world scenario.
7. Purane topics baad ke exams mein dobara aayenge (spaced repetition).
