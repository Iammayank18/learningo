HOW TO USE THIS
This is a reference. Do not read it front to back.
Every other journal in this folder teaches a subject. This one does not. It is a decision reference for building AI features that survive production — open it when you hit a decision, read that one card, then go back to the code. Each card is the same shape: what the decision is, why it matters, where you will hit it in your own projects, and the gotchas that cost other people time.

There are no exams here, no mastery gates and no schedule. The checkboxes are for your own memory, nothing else. If you want the fastest path in: read Phase 3 — Evaluation Architecture first. It is the skill everything else depends on, and it is the one almost nobody has.
