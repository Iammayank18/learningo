Rules — atomic topic · 6-unit budget · mastery gate · lock system

1 — Atomic topic. Ek period mein ek hi topic. Agar explain karte waqt doosra topic samjhana pad raha hai, toh woh do topics the — todo, doosre ko buffer mein daalo.

2 — Din ka budget 6 unit. Light 1 · Medium 1.5 · Heavy ▲ 2. Din ka total budget se upar gaya toh aakhir se period gir jaate hain buffer mein. Har din ke header pe uske units likhe hain. Isliye zyadatar din 3 period ke hain, kuch 4 ke.

3 — Weekly grid. DSA 4 · JavaScript 3 · React/FE 3 · Machine Coding 3 · Browser/Web 2 · SysDesign 2 · Behavioral 1 = 18 sessions + 2 buffer (10%).

Start date set kar doge toh exam us week ke Sunday se khulega. Nahi set kiya toh sirf Sunday ko khulega. Jaldi khatam kar loge toh bhi exam apne din se pehle nahi khulega — aur agla term dikhega hi nahi.

6 — Spiral revision. D+7, D+21, D+56. Har Saturday: is hafta + pichhla hafta + 3 hafte pehle.

7 — Predicted score pehle likho. Actual ka box tab tak band rahega. Asli data gap hai, score nahi.

8 — Google Doc rule. DSA aur frontend-round ki saari practice ek plain Google Doc mein — no autocomplete, no syntax highlighting, no run button. Google ka asli interview isi mein hota hai. IDE mein practice karke doc mein fail hona sabse common trap hai.

9 — Speed rule. Ek medium 20 minute mein na aaye toh woh topic mastered nahi hai. Google ka bar "eventually solve" nahi, "15–20 min mein solve" hai. A-gate ka matlab hi timed solve hai.

10 — DSA problem volume. 16 hafte ka target 190 problems. Har week ke header pe uska apna target hai aur counter bhi — number wahin bharo. Sirf topic samajhna kaafi nahi, volume chahiye (Grind 75 = 75 problems, NeetCode 150 = 150).
